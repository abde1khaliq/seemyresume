## DESIGN PHILOSOPHY (Anti-AI-Slop)

### Typography - The #1 Differentiator

NEVER use these fonts (they scream "AI-generated"):
- Inter, Roboto, Arial, system-ui
- Poppins, Open Sans, Lato
- Montserrat, Raleway

ALWAYS use distinctive, characterful fonts:
- Display/Heading: Space Grotesk, Outfit, Syne, Clash Display, Satoshi, Cabinet Grotesk, DM Serif Display, Playfair Display, Bebas Neue
- Body: IBM Plex Sans, DM Sans, Plus Jakarta Sans, Manrope, Source Sans 3

Typography rules:
- Mix a bold display font with a refined body font
- Use dramatic size contrasts (hero name should be 4-6rem)
- Experiment with weight (bold headings, regular body)
- Consider letter-spacing for display text
- Never make all text the same size

### Layout - Break the Grid

NEVER:
- Rigid 4-column grids with equal card sizes
- Predictable section order (features → pricing → testimonials)
- Edge-to-edge everything without breathing room
- Cookie-cutter card layouts

ALWAYS:
- Dynamic layouts with varying element sizes
- Asymmetric compositions where appropriate
- Surprising whitespace - frame content like a museum piece
- Break the grid intentionally for emphasis
- Create visual hierarchy through size and position

### Visual Effects - Depth and Life

Use 2-3 of these effects (don't overdo):
- Glassmorphism: frosted glass with backdrop-blur
- Subtle gradients: not rainbow, intentional color flows
- Depth shadows: layered shadows for dimension
- Glow effects: subtle, not neon
- Background patterns: dots, grid, noise texture
- Border accents: thin colored borders on cards

### Color Philosophy

Match the user's requested style EXACTLY.
If no specific request, choose based on profession:
- Developers: Dark with green/blue accents, terminal vibes
- Designers: Bold creative palettes, unexpected combinations
- Business: Professional navy/indigo with accent highlights
- Creative roles: Expressive, vibrant, memorable

Never use:
- Generic blue (#3B82F6) as primary without reason
- Gray (#6B7280) for all text
- Rainbow gradients

### Animation Philosophy

Subtle and intentional, not aggressive:
- Fade-in on scroll for sections
- Smooth hover states (transform, box-shadow changes)
- Staggered reveals for lists (animation-delay)
- Smooth transitions (300-500ms)

Avoid:
- Bouncing, spinning, pulsing
- Aggressive color changes
- Attention-seeking movements
